# Effective Mobile DevOps Test

Представлено простое веб-приложение с использованием Docker и Docker Compose. 
Приложение состоит из backend-сервиса и nginx, который используется в качестве reverse proxy.
Backend представляет собой минимальный HTTP-сервер на Python, который отвечает текстом "Hello from Effective Mobile!" на запрос по пути /. Backend-сервис слушает порт 8080 и доступен только внутри docker-сети.
Для запуска проекта необходимо перейти в корень репозитория и выполнить следующие команды:

docker compose build  
docker compose up

После выполнения команд будут запущены два контейнера: backend и nginx.

Для проверки работы приложения нужно выполнить команду:

curl http://208.123.190.31

В ответ должен вернуться следующий текст:

Hello from Effective Mobile!

Принцип работы следующий: пользователь отправляет HTTP-запрос на порт 80, который принимает контейнер nginx. Далее nginx проксирует запрос на backend-сервис внутри docker-сети. Backend обрабатывает запрос и возвращает ответ, который nginx отправляет пользователю. Backend-контейнер не имеет проброса портов на хост и недоступен напрямую извне.

Схема взаимодействия сервисов:

Пользователь -> nginx (80) -> backend (8080)
